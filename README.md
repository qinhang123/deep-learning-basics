# Deep Learning Basics

深度学习基本原理：前向传播、Softmax、交叉熵与梯度下降的最小实现与演示代码。

## 目录结构

- `CrossEntropy.py`
- `DNNforward.py`
- `GradientDescent.py`
- `model.bin`
- `Softmax.py`
- `TorchDemo.py`
- `深度学习原理.pptx`

## 快速开始

各示例代码可直接运行，具体参数见源码内注释。

## 说明

- 模型权重、向量库、安装包等大文件未纳入仓库，所需模型请按代码中的名称从 HuggingFace 或对应官方渠道下载。
- 请通过环境变量配置 API Key（如 `DASHSCOPE_API_KEY`、`DEEPSEEK_API_KEY`），仓库中不包含任何密钥。
